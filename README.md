# KNR + UTTNH 兼容补丁 (KNR & UTTNH Compatibility Patch)

本模组是 **VNR + UTTNH 兼容包** 的子模组。实现了在 **KR (Kaiserreich)** 下，**KNR (Kaiserreich Naval Rework)** 与 **UTTNH_2.0** 的兼容。

主要实现了对**KR**与**UTTNH**的有限兼容和对**VNR + UTTNH 兼容包**与**KNR**的兼容

对非海军科技树中的研究倾向做了如下调整：
- **四个美国**将和原版环境下的美国研究倾向相同
- **德属东亚** 与 **日本** 的研究倾向类似

---

## ⚠️ 兼容性与使用须知

### 1. 模组需求
推荐排列顺序：
1. **Kaiserreich (KR)**
2. **KNR (Kaiserreich Naval Rework)**
3. **UTTNH (Ultimate Tech Tree : New Horizons)**
4. **VNR + UTTNH 兼容包**
5. **本模组 (KNR + UTTNH 兼容补丁)**

### 2. 额外提示
* **不要与 VNR (Vanilla Navy Rework) 同时使用**。

---

本模组基于 VNR + UTTNH 兼容包框架进行调整，仅供《钢铁雄心IV》模组交流使用。
